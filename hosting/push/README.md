# Skybee Push (Web Push на власному хостингу)

Для сайту й PWA, коли вкладка закрита. Користувач у Налаштування → Сповіщення вставляє **пароль застосунку** (для чатів — з галочкою
«Allow access to your direct messages»). Сервер раз на хвилину питає Bluesky про нове і шле Web Push.
Лише PHP ≥ 8.1 з `openssl` і `curl`; бази даних немає (файли в `data/subs`).

## Встановлення (один раз)
1. CI (`hosting.yml`) заливає `push/` разом із сайтом. `config.php` і `data/` у репозиторії немає — вони лишаються на сервері.
2. У консолі хостингу: `cd <тека сайту>/push && php keygen.php` — скопіюй вивід у **новий** `config.php` за зразком `config.example.php`
   (там же `subject`, `origins`). Бажано `data_dir` поза текою сайту.
3. Cron на хостингу раз на хвилину (мінімум, що дозволяє NIC.UA): `php <шлях>/push/cron.php` або
   `wget -q -O- "https://skybee.online/push/cron.php?key=<cron_key>"`.
4. Перевірка: у застосунку увімкни Push — має прийти «Push увімкнено».

## Безпека
- Сервер **відхиляє основний пароль** (приймає лише пароль застосунку, перевіряє scope токена). Токени сесії (`jwt`, `refresh`) лежать так само зашифрованими; ім'я файлу — HMAC від DID.
- Усі запити сервера йдуть лише на публічні IP (без приватних діапазонів, з прив'язкою IP проти DNS-rebinding), відповідь ≤ 1 МБ, таймаут 8 с. Помилки з паролями в вивід не потрапляють.
- Ліміти спроб: 12/год з адреси (IPv6 — /64) і 6/год на нік. Cron не накладається сам на себе; один зіпсований запис не зупиняє інших.
- Пароль застосунку шифрується AES-256-GCM (`enc_key` лише в `config.php`), на кожному вході видається окремий токен відписки.
  Коли відписано всі пристрої акаунта, запис із паролем видаляється. Три невдалі входи поспіль (пароль відкликано) — теж.
- `.htaccess` закриває все, крім `api.php` і `cron.php`. API приймає запити лише з `origins`, 12 спроб на годину з адреси.
- Push-адреса має бути справжнім сервісом браузера (Google, Mozilla, Apple, Microsoft) — інакше підписку відхилено.
- Користувачу радимо окремий пароль застосунку лише для Skybee Push: його можна відкликати в налаштуваннях Bluesky.
