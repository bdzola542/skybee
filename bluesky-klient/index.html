Skybee — клієнт для Bluesky українською

Skybee — це безкоштовний відкритий застосунок для соцмережі Bluesky (AT Protocol). Працює в браузері, а також як програма для Windows, Linux, Android та iPhone. Заходите зі своїм акаунтом Bluesky, краще з паролем застосунку.

Що вміє Skybee

  • Колонки поруч: кілька стрічок, списків і пошуків на одному екрані, навіть від імені різних акаунтів
  • Власні стрічки без сервера: злиття джерел, ключові слова, фільтри — усе на вашому пристрої
  • Чати, групи, реакції, відповіді; сповіщення, зокрема в браузері при закритій вкладці
  • Планувальник постів, кілька чернеток, закладки з папками й пошуком
  • Аналітика профілю: ріст читачів, залученість, хто відписався, хто не підписаний у відповідь
  • Оформлення профілю для користувачів Skybee: колір, статус, трек Apple Music
  • Теми Skybee, Liquid Glass (як на iPhone) і Material Design 3, кольори застосунку, шрифти
  • Інтерфейс багатьма мовами, зокрема українською, англійською, польською, німецькою
  • Модерація: фільтри контенту, приховані слова, сторонні сервіси міток, списки

Де працює

  • Веб: skybee.online — без встановлення, можна додати на головний екран
  • Windows: інсталятор із автооновленням
  • Linux: Flatpak
  • Android: APK
  • iPhone: IPA для встановлення через Sideloadly чи AltStore

Часті запитання

Що таке Skybee?

Skybee — неофіційний клієнт Bluesky з відкритим кодом: інший інтерфейс до тієї самої мережі й тих самих акаунтів.

Це безкоштовно?

Так, Skybee безкоштовний, код відкритий на GitHub.

Чи безпечно входити?

Рекомендується пароль застосунку Bluesky: його можна відкликати будь-коли. Основний пароль Skybee використовує лише за вашим явним вибором.

Чи є Skybee для Windows і телефонів?

Так: програма для Windows, Flatpak для Linux, APK для Android та файл для iPhone. Усі файли — у розділі Releases на GitHub.
