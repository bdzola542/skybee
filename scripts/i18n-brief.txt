Формат — як у `js/i18n/sk.js` (прочитай перші ~40 рядків і ~30 випадкових із середини, щоб схопити стиль): `export default { "український текст": "переклад", ... };` з першим рядком-коментарем `// Skybee interface — {NAME} (missing lines fall back to English). Keys: the Ukrainian text (i18n/keys.json, scripts/i18n-extract.mjs); {0}… — parts that change.`
Ключі — усі ~1552 рядки з `i18n/keys.json` (ключі цього JSON — український текст інтерфейсу). Для довідки є готові `js/i18n/en.js` (англійська), `pl.js`, `sk.js` — дивись на них, щоб зрозуміти контекст короткого слова (кнопка, меню, заголовок), але перекладай з українського, звіряючись з англійським.

Правила:
- Переклад природний, як у справжній локалізації соцмережі (Bluesky/Twitter цією мовою): коротко, без калькування. Звертання до користувача — в тоні, прийнятому для інтерфейсів цією мовою.
- Збережи без змін усі `{0}`, `{1}`… (змінні частини; кількість і номери ті самі), емодзі на краях, `@`, `#`, `%`, назви: Skybee, Bluesky, Liquid Glass, Material, PDS, DID, ALT, GIF, QR, RSS, LIVE.
- Ключі — точно як у keys.json (символ у символ), у JSON-рядках екрануй `"` і `\`. Ключ без змісту для перекладу пропускай. Покрий усі ключі (≈1550 рядків); 5 перших ключів — мета-теги index.html — теж переклади.
- Нелатинське письмо мови — своїм письмом; решта — без залишків кирилиці.
- Файл завеликий для одного запису: пиши частинами (по ~200–250 ключів). Спосіб: виводь ключі порціями (скрипт читає i18n/keys.json, друкує ключі з номерами від–до), перекладай порцію й дописуй у файл (перший запис — Write із початком `export default {`, далі додавай рядки через Bash-heredoc `cat >> файл <<'EOF2'`; наприкінці закрий `};`). Перекладай сам, без зовнішніх сервісів перекладу.
- Перевірка наприкінці (обов'язково, виправ усе знайдене): `node --check --input-type=module < js/i18n/{CODE}.js` та `node scripts/i18n-check.mjs {CODE}` — має бути «bad placeholders 0, cyrillic 0» (для кириличних мов cyrillic не рахується), пропущених ≈0.
- Фінальна відповідь — 3–4 рядки українською: скільки рядків, результат перевірки, сумніви у перекладі (якщо є). Словник у відповідь не вставляй.
